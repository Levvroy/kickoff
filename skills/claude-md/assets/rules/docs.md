# Aturan dokumen
- Ikuti struktur template asli. Jangan menghapus atau mengganti nama bab tanpa persetujuan.
- Setiap ID baru didaftarkan dulu di `docs/00-id-registry.md`.
- Nama aktor, use case, dan kelas harus identik di semua dokumen.
- Klaim faktual merujuk `[S-xx]`. Tanpa sumber berarti `[ASUMSI]`.
- Perubahan dari versi sebelumnya dicatat di tabel Daftar Perubahan.
