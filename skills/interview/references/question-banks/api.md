# Bank pertanyaan: API / Backend
- Siapa konsumen API (frontend sendiri, mitra, publik)?
- Gaya: REST, GraphQL, gRPC, WebSocket? Ada kontrak (OpenAPI) yang harus diikuti?
- Autentikasi: API key, OAuth2, JWT, mTLS?
- Target latensi dan throughput? SLA ketersediaan?
- Rate limit, kuota, dan versioning?
- Idempotensi untuk operasi penting (pembayaran, pemesanan)?
- Logging, monitoring, audit trail?
- Data apa yang disimpan, retensi berapa lama, dan backup?
